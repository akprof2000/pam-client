## [1.0.0] — 2026-09-03

Первый выпуск.

### Добавлено

- Библиотека `pam`: получение секрета через AAPM REST API с автоматическим
  определением типа записи (логин/пароль, данные, SSL-сертификат, SSH-ключ).
- Метод `ListAccounts` — список записей, доступных токену.
- Проверка TLS включена по умолчанию; опции для корпоративного УЦ,
  взаимного TLS и отключения проверки на стендах.
- Повторы при сетевых сбоях и ответах 429/5xx с экспоненциальной выдержкой.
- Вырезание токена из текстов сетевых ошибок.
- Утилита `pamget` с оформленным выводом в консоль и режимами
  `-raw`, `-field`, `-json`, `-list`.
- Имитация сервера `pam/mockpam` и команда `fakepam` для локальной отладки.
- Демонстрационные сценарии `scripts/demo.sh` и `scripts/demo.ps1`.
- Сборка релизных архивов для Windows и Linux (amd64, arm64).
